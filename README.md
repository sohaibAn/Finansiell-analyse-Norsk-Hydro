# Finansiell analyse: Norsk Hydro

Dette prosjektet ble gjennomført som en del av kurset **BUS220 – Finansiering og investering** ved Handelshøyskolen NMBU.

## 📄 Om prosjektet
Vi analyserte Norsk Hydro som investeringsobjekt. Rapporten dekker finansiell ytelse, risiko, aksjeprising og bærekraftsfaktorer.

## 🔍 Innhold
- Beregning av nøkkeltall: P/E, P/B, EPS, ROE, WACC, gjeldsgrad
- Vurdering av aksjeverdi og kapitalkostnad (Gordon Growth Model)
- Analyse av kapitalstruktur og utbyttepolitikk
- Risikovurdering: Beta, usystematisk risiko og klimarisiko

## 🧠 Læringsmål
- Bruke regnskapsdata til å analysere børsnoterte selskaper
- Vurdere investeringsrisiko og verdi
- Tolke effekter av bærekraft og klima på finansielle beslutninger
